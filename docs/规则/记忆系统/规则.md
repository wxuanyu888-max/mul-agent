## 业务约束

### 参数范围

| 参数 | 类型 | 取值范围 | 默认值 | 说明 |
|------|------|----------|--------|------|
| short_term_max_size | string | - | 10MB | 短期记忆最大存储 |
| short_term_ttl | int | 60-86400 | 3600 | 短期记忆过期秒数 |
| long_term_compression | bool | true/false | false | 长期记忆是否压缩 |
| archive_interval | string | hourly/daily/weekly | daily | 归档间隔 |

### 核心逻辑

1. 短期记忆：会话级，由Agent自行管理
2. 长期记忆：JSON文件持久化，Agent自行决定写入时机
3. 交接文档：Agent自己生成，指定下一个Agent读取什么

### 边界情况

- 存储空间不足：清理最旧的短期记忆
- 记忆文件损坏：返回错误，不影响系统运行
- 归档失败：保留原文件，记录错误日志

### 判断规则

| 场景 | 判断条件 | 结果 |
|------|----------|------|
| 短期记忆过期 | 当前时间 - 创建时间 > TTL | 自动清理 |
| 归档触发 | 到达指定间隔 | 归档到历史目录 |
| 记忆检索 | 搜索关键词匹配度 < 阈值 | 不返回结果 |

## 技术约束

### 技术选型原则

- 存储格式使用JSON，便于Agent解析
- 文件命名包含时间戳，便于排序和清理

### 存储结构

```
memory/
├── short_term/
│   └── session_{id}.json
├── long_term/
│   └── {agent_id}.json
└── handover/
    └── {from}_{to}_{timestamp}.json
```
