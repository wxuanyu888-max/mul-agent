# 存储格式规范

本文档规定项目中不同类型数据的存储格式、文件命名规范和目录结构。

---

## 一、格式选择原则

| 格式 | 适用场景 | 理由 |
|------|----------|------|
| `.jsonl` | 对话历史、流水数据 | 每行独立可追加、适合程序解析、人类可读 |
| `.md` | 记忆、摘要、文档 | 需要人类阅读、有元数据+正文结构 |
| `.json` | 配置文件、API 响应 | 机器解析为主、结构固定 |
| `.yaml` / `.yml` | 配置定义 | 人类编写、层次清晰 |
| `.txt` | 临时日志、简单输出 | 极简场景、无结构需求 |

---

## 二、具体规范

### 1. 对话历史 (Conversation)

| 项目 | 规范 |
|------|------|
| **格式** | `.jsonl` (JSON Lines) |
| **目录** | `storage/conversations/{agent_id}/{session_id}/` |
| **分页** | 按日期分文件，如 `20260305.jsonl` |
| **每行结构** | `{ "id": "...", "role": "...", "content": "...", "timestamp": "..." }` |
| **压缩文件** | `compressed_summary.md` (摘要) |

**示例路径**:
```
storage/conversations/core_brain/session_xxx/20260305.jsonl
```

### 2. 记忆 (Memory)

| 项目 | 规范 |
|------|------|
| **格式** | `.md` (Markdown) |
| **目录** | `storage/memory/{type}/{agent_id}/` |
| **类型** | `short_term/` / `long_term/` / `handover/` |
| **元数据** | YAML Front Matter |
| **正文** | Markdown 格式 |

**示例**:
```markdown
---
id: 0081cbd34f6efb8c
agent_id: core_brain
type: short_term
timestamp: 2026-03-05T18:42:36.765201
---

# 记忆

- **input**: 用户输入内容
- **action**: 执行的操作
```

### 3. 压缩摘要

| 项目 | 规范 |
|------|------|
| **格式** | `.md` (Markdown) |
| **位置** | 对话历史目录内 `compressed_summary.md` |
| **用途** | 长期对话的摘要，供人类和 Agent 查阅 |

### 4. 配置文件

| 项目 | 规范 |
|------|------|
| **Agent 配置** | `.md` (用户可编辑) |
| **系统配置** | `.json` 或 `.yaml` |
| **目录** | `storage/agents/{agent_id}/` |

**Agent 配置结构**:
```
storage/agents/core_brain/
├── soul.md    # 灵魂配置
├── user.md    # 用户配置
├── skill.md   # 技能配置
└── memory.md  # 记忆配置
```

### 5. 临时文件

| 项目 | 规范 |
|------|------|
| **格式** | `.txt` 或 `.log` |
| **目录** | `storage/temp/` 或 `storage/logs/` |
| **清理** | 定期清理，过期自动删除 |

---

## 三、文件命名规范

### 基本规则

1. **英文小写 + 下划线**: `conversation_manager.py`
2. **避免特殊字符**: 仅使用字母、数字、下划线、连字符
3. **有意义**: 名称应反映文件内容

### 时间戳格式

- **文件名**: `YYYYMMDD` 或 `YYYYMMDD_HHMMSS`
- **文件内 timestamp**: ISO 8601 `YYYY-MM-DDTHH:MM:SS.ffffff`

### ID 生成

| 类型 | 格式 | 示例 |
|------|------|------|
| 消息 ID | `msg_{hash8}` | `msg_0081cbd3` |
| 会话 ID | `session_{uuid}` | `session_abc123` |
| Agent ID | `{role}_{name}` | `core_brain` |

## 四、目录结构总览

```
storage/
├── agents/                    # Agent 配置文件
│   └── {agent_id}/
│       ├── soul.md
│       ├── user.md
│       ├── skill.md
│       └── memory.md
├── memory/                   # 记忆系统
│   ├── short_term/{agent_id}/   # 短期记忆 (.md)
│   ├── long_term/{agent_id}/    # 长期记忆 (.md)
│   └── handover/              # 交接文档 (.md)
├── conversations/            # 对话历史
│   └── {agent_id}/{session_id}/
│       ├── 20260305.jsonl    # 按日期分页
│       ├── 20260306.jsonl
│       └── compressed_summary.md  # 压缩摘要
├── temp/                     # 临时文件 (.txt)
└── logs/                    # 日志文件 (.log)
```

---

## 五、格式转换规则

| 场景 | 转换方向 | 说明 |
|------|----------|------|
| 读取外部数据 | 任意 → JSON | 内部统一用 dict 处理 |
| 持久化存储 | JSON → 对应格式 | 按本规范选择格式 |
| 压缩摘要 | JSONL → MD | LLM 摘要生成 |
| 导出备份 | 任意 → JSON | 统一导出为 JSON |

---

## 六、注意事项

1. **不要混用格式**: 同一类型数据必须使用统一格式
2. **保持可读性**: 优先选择人类可读的格式（MD > JSON > 二进制）
3. **版本兼容**: 配置文件添加 `version` 字段
4. **自动清理**: 临时文件和过期记忆定期清理
