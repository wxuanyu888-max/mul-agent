## 用户故事

### 用户故事 1：启动核心大脑

作为 开发者
我希望 执行一条命令就能启动核心大脑
以便 开始与Agent系统交互

验收标准：
- [ ] 执行 python main.py --brain 可启动核心大脑
- [ ] 系统输出欢迎信息
- [ ] 进入交互模式

### 用户故事 2：创建新Agent

作为 核心大脑
我希望 能够创建新的Agent成员
以便 将复杂任务分解给多个Agent协作处理

验收标准：
- [ ] 调用create_user路由可创建新Agent
- [ ] 自动生成新Agent的配置文件（soul.json、user.json、skill.json、memory.json）
- [ ] 返回创建成功的响应

### 用户故事 3：自我进化

作为 核心大脑
我希望 能够自主修改自身配置进行进化
以便 不断提升自身能力

验收标准：
- [ ] heart路由可触发自省流程
- [ ] 可修改soul.json、user.json、skill.json、memory.json
- [ ] 修改前自动创建版本快照
- [ ] 修改后可热重载配置
