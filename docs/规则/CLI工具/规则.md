## 业务约束

### 参数解析规则

| 参数 | 类型 | 取值范围 | 默认值 | 说明 |
|------|------|----------|--------|------|
| 长选项 | string | --xxx | - | 使用双横线 |
| 短选项 | string | -x | - | 使用单横线+单字母 |
| 参数值 | string | - | - | 等号或空格连接 |

### 输出格式规则

| 场景 | 输出格式 | 示例 |
|------|----------|------|
| 正常输出 | 纯文本或JSON | `{"status": "success"}` |
| 错误输出 | 纯文本错误信息 | `Error: xxx` |
| 帮助信息 | 标准格式 | `Usage: python main.py [OPTIONS]` |

### 退出码规范

| 码 | 说明 |
|-----|------|
| 0 | 成功 |
| 1 | 通用错误 |
| 2 | 参数错误 |
| 3 | 配置错误 |
| 4 | 执行超时 |
| 5 | 权限不足 |

## 交互模式约束

### REPL 设计原则

- 退出命令：支持 `exit`、`quit`、`Ctrl+C`
- 历史记录：支持上下箭头翻阅
- 提示符：显示当前Agent名称
