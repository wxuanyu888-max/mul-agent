## ⚠️ 注意事项

1. **多轮对话时的文件状态**：
   - 文件内容可能会被覆盖（取决于 LLM 生成的命令）
   - 建议每轮对话之间验证文件状态

2. **上下文压缩**：
   - 长链路（>10 轮）可能需要压缩上下文
   - 当前压缩阈值：8000 tokens

3. **记忆管理**：
   - 短期记忆：自动保存到磁盘
   - 长期记忆：需要手动归档

4. **LLM 依赖**：
   - 部分决策依赖 LLM 响应
   - 无 LLM 时使用规则路由
