## 问题分析

你提到的问题：
1. 看不出 Agent 指挥团队的能力
2. 看不出问题解决的思路

**根本原因**：原有提示词只是机械的规则定义，没有说明"如何在上下文中找到解决方法"。

## 核心改进

### 1. 上下文感知决策

```
用户输入
    │
    ▼
1. 上下文分析
   - 字面意思 vs 潜在需求
   - 检索历史记忆
   - 评估系统状态
    │
    ▼
2. 问题分类
   - 简单 → 直接处理
   - 中等 → LLM 辅助
   - 复杂 → 团队委派
    │
    ▼
3. 执行并学习
   - 执行行动
   - 记录结果到记忆
   - 更新决策模型
```

### 2. 团队指挥能力

| 步骤 | 行动 |
|------|------|
| 识别需求 | 分析任务需要的技能类型 |
| 查找 Agent | 从网络中找到专业 Agent |
| 明确任务 | 传达任务要求和上下文 |
| 跟踪进度 | 监控各 Agent 工作状态 |
| 汇总结果 | 整合后统一反馈给用户 |

### 3. 隐式意图识别

| 用户输入 | 真实意图 | 路由 |
|---------|---------|------|
| "看看这个"（上文有文件） | 查看文件内容 | bash (cat) |
| "项目结构怎么样" | 分析项目结构 | bash (find/tree) |
| "有哪些依赖" | 查看依赖列表 | bash (pip list) |
| "交给专业人士处理" | 委派任务 | chat → network_delegate |

## 使用方法

### 1. 加载提示词

系统初始化时加载 `prompt.md` 作为主要输入：

```python
# 伪代码示例
def build_context(agent_id, user_input):
    # 1. 加载基础配置
    soul = load_yaml(f"wang/agent-team/{agent_id}/soul.md")
    user = load_yaml(f"wang/agent-team/{agent_id}/user.md")
    logic = load_yaml(f"wang/agent-team/{agent_id}/logic.md")
    memory_config = load_yaml(f"wang/agent-team/{agent_id}/memory.md")

    # 2. 加载主提示词
    prompt = load_text(f"wang/agent-team/{agent_id}/prompt.md")

    # 3. 检索记忆
    short_term = retrieve_short_term_memory(agent_id)
    long_term = retrieve_long_term_memory(agent_id)

    # 4. 构建完整上下文
    return {
        "system": prompt,
        "config": {
            "soul": soul,
            "user": user,
            "logic": logic,
            "memory": memory_config
        },
        "context": {
            "short_term": short_term,
            "long_term": long_term,
            "user_input": user_input
        }
    }
```

### 2. 决策流程

在 `brain.py` 的 `_decide_action` 方法中：

1. 先规则匹配（快速路径）
2. 无法匹配时检索记忆
3. LLM 分析生成响应
4. 记录结果到记忆
