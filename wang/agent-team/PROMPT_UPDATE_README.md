# 提示词系统更新说明 - v2.0

## 核心理念

> **一个 Agent 最大的能力，就是在当前的上下文中找到解决问题的方法。**

本次更新围绕"上下文感知"这一核心理念，全面重构了 Agent 的提示词系统。

## 设计原则

### 1. 上下文优先
所有决策前先分析上下文：
- 字面意思 vs 潜在需求
- 历史记忆中的相似场景
- 当前系统状态

### 2. 记忆驱动
- 路由决策前检索记忆
- 执行行动前查找方案
- 执行行动后记录经验

### 3. 渐进式披露
- 基础能力始终可用
- 协作能力情境触发
- 专家能力按需披露

### 4. 团队指挥
- 识别专业需求
- 评估复杂度决定委派
- 并行优先
- 结果汇总

## 使用指南

### 加载提示词

系统应该在初始化时加载：
1. `prompt.md` - 作为主要系统提示词
2. `soul.md` - 作为 Agent 人格配置
3. `user.md` - 作为角色和能力配置
4. `logic.md` - 作为路由逻辑配置
5. `memory.md` - 作为记忆系统配置
6. `skill.md` - 作为能力披露配置

### 上下文构建

```python
context = {
    "soul": load_yaml("soul.md"),
    "user": load_yaml("user.md"),
    "logic": load_yaml("logic.md"),
    "memory": load_yaml("memory.md"),
    "skill": load_yaml("skill.md"),
    "prompt": load_text("prompt.md"),
    "short_term_memory": retrieve_short_term(),
    "long_term_memory": retrieve_long_term(),
    "conversation_history": get_history()
}
```

## 预期效果

更新后的 Agent 应该能够：

1. **理解上下文**
   - 理解"这个文件"、"那个功能"等指代
   - 保持对话的连贯性

2. **从历史学习**
   - 检索相似场景的解决方案
   - 根据用户偏好调整响应

3. **智能决策**
   - 不只是机械匹配规则
   - 根据复杂度决定自主处理还是委派

4. **指挥团队**
   - 识别需要的专业技能的
   - 找到合适的 Agent 委派
   - 汇总结果统一反馈
