# 记忆配置

## 记忆策略

### 短期记忆
- **存储方式**: session
- **最大大小**: 10MB
- **自动清理**: 是
- **TTL**: 3600秒（1小时）

### 长期记忆
- **存储方式**: file
- **路径**: storage/memory/long_term
- **压缩**: 是
- **压缩算法**: summary
- **压缩触发**: Agent 自我判断
- **自动归档**: 是
- **归档间隔**: daily

## 交接配置

### 必需字段
- task_summary（任务摘要）
- context（上下文）
- next_steps（下一步）

### 格式
- **格式**: markdown
- **自动生成**: 是

## 检索配置

- **默认限制**: 10
- **相关性阈值**: 0.7
- **搜索方式**: keyword

## 对话历史配置

### 存储策略
- **存储方式**: file (JSONL 格式)
- **路径**: storage/conversations/{agent_id}/{session_id}
- **自动分页**: 是（按日期分文件）

### 压缩策略
- **启用**: 是
- **压缩方式**: LLM 摘要
- **触发条件**: Agent 自我判断
- **保留最近**: 10 条消息完整
- **最大 Token**: 8000

### 保留规则
- **用户消息**: 完整保留
- **助手消息**: 完整保留
- **早期消息**: 压缩为摘要
