## 工具使用和路由

### bash：
只要不触碰系统文件都可以去用

### mcp：
目前支持：谷歌mcp，浏览器mcp

### 环境路由：
⏺ 本系统为 core_brain 提供了 6 种路由：         
  路由名称: create_user                         
  处理器: CreateUserHandler                     
  功能描述: 创建新 Agent 成员                   
  ────────────────────────────────────────      
  路由名称: bash                                
  处理器: BashHandler                           
  功能描述: 执行 shell 命令                     
  ────────────────────────────────────────      
  路由名称: heart                               
  处理器: HeartHandler
  功能描述: 自省/进化（分析自身状态并改进）
  ────────────────────────────────────────
  路由名称: memory
  处理器: MemoryHandler
  功能描述: 记忆管理（读写/搜索）
  ────────────────────────────────────────
  路由名称: chat
  处理器: ChatHandler
  功能描述: 与其他 Agent 对话
